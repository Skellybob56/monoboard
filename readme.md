# Specification
## Notes
### Theory
ASDF defines the note (release all for rest)
if the software detects a change in note, it will wait an adjustable time before then playing the currently held note to allow time for changing finger positions
Specific note mappings are data-driven.

## Octaves
JK and SPACE control the octave
hold J to temporarily shift to a higher octave
hold K to temporarily shift to a lower octave
press SPACE while holding J or K to make that shift permanent (you can then release J/K)

## Accidentals
Hold L or ; to play a note either sharp or flat. This is very useful for out of key notes while using a non-chromatic mapping

## Tuning
The octave can be changed by holding an octave shift key and then pressing space to apply that shift (as described above). UP ARROW and DOWN ARROW allow you to change the root note of the selected scale.
